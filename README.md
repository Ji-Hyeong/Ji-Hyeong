# 강지형 | Backend Engineer

결제·구독·인증처럼 복잡한 비즈니스 흐름을 안정적인 시스템으로 구현해 온 백엔드 엔지니어입니다.

5년 이상의 실무 경험을 바탕으로 기능 구현에 그치지 않고 데이터 정합성, 실패 복구, 동시성 제어와 운영 안정성을 함께 고민합니다. Kotlin/Java와 Spring Boot를 주로 사용하며, 요구사항 분석부터 설계·개발·출시·운영까지 제품의 전체 흐름에 참여해 왔습니다.

## Engineering Focus

- **Payment & Subscription** — 정기 결제, 재시도, 중복 방지, 해지와 권한 회수까지 이어지는 전체 수명주기 설계
- **Consistency & Reliability** — Transactional Outbox, 멱등 처리, 원장형 데이터 모델과 보상 흐름 설계
- **Authentication** — JWT 기반 Access/Refresh Token 분리와 레거시 인증의 무중단 점진 전환
- **Concurrency & Performance** — Redis 분산 락, Sorted Set, 캐시를 활용한 동시성·성능 문제 해결
- **Production Ownership** — 장애 원인 분석, 긴급 복구, 재발 방지와 후속 서비스 재사용까지 책임지는 개발

## Tech Stack

- **Backend:** Kotlin, Java, Spring Boot, Spring MVC, JPA/Hibernate, C#/.NET
- **Data:** PostgreSQL, MySQL, Redis
- **Messaging & Cloud:** Azure Service Bus, AWS, Azure
- **Testing & Delivery:** JUnit 5, Gradle, Docker Compose, GitHub Actions
